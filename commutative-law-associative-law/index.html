什么是交换律？

交换律说的是：交换两个数的位置，运算结果不变。 但并非所有运算都满足交换律——

成立 加法：a + b = b + a   （例：3 + 5 = 5 + 3 = 8）

成立 乘法：a × b = b × a   （例：4 × 7 = 7 × 4 = 28）

不成立 减法：a − b ≠ b − a（例：8 − 3 = 5，但 3 − 8 = −5）

不成立 除法：a ÷ b ≠ b ÷ a（例：12 ÷ 4 = 3，但 4 ÷ 12 ≈ 0.33）

生活中的交换律

想象你有 3 个苹果 和 5 个橙子：

先数苹果再数橙子：3 + 5 = 8 个水果

先数橙子再数苹果：5 + 3 = 8 个水果

无论先数哪个，总数不变——这就是加法交换律在日常中的体现。

什么是结合律？

结合律说的是：三个数运算时，先算前两个还是先算后两个，结果不变。 它决定了括号可以"挪位置"。

成立 加法：(a + b) + c = a + (b + c)

成立 乘法：(a × b) × c = a × (b × c)

不成立 减法：(a − b) − c ≠ a − (b − c)

不成立 除法：(a ÷ b) ÷ c ≠ a ÷ (b ÷ c)

关键区别：交换律是"换位置"，结合律是"移括号"。两者是独立的性质。

生活中的结合律

你有 2 个苹果、3 个苹果 和 4 个苹果：

先把前两堆合并再加入第三堆：(2 + 3) + 4 = 5 + 4 = 9

先把后两堆合并再加入第一堆：2 + (3 + 4) = 2 + 7 = 9

无论先合并哪两堆苹果，总个数始终不变——这就是加法结合律。

什么是一元一次方程？

一元一次方程是只含一个未知数（元）且未知数最高次数为 1（次） 的方程。 标准形式：ax + b = 0（a ≠ 0）。

例如：3x + 5 = 2x + 7、2x − 3 = 1、−x + 4 = 6

核心思想——移项变号：将含有未知数的项移到等号左边，常数项移到等号右边。 跨过等号时，+ 变 −、− 变 +。这是最关键也最容易错的一步！

去括号——符号变化规则

方程中经常出现括号，去掉括号时符号如何变化是解题的关键。 规则取决于括号前面的符号：

规则一：括号前是 +

去掉括号和前面的 + 号，括号内各项符号不变

a + (b − c) = a + b − c

a + (−b + c) = a − b + c

规则二：括号前是 −

去掉括号和前面的 − 号，括号内各项全部变号

a − (b + c) = a − b − c

a − (b − c) = a − b + c

规则三：括号前是系数

用乘法分配律展开系数，符号跟随系数

2(x − 3) = 2x − 6

−3(x + 2) = −3x − 6

单位换算——规则与思考

单位换算的核心是记住进率（相邻单位之间的倍数关系），然后根据进率进行乘除运算。 大单位 → 小单位用乘法；小单位 → 大单位用除法。

换算口诀：大化小，乘进率；小化大，除进率。进率就是相邻两个单位之间的倍数。
