# 数学运算探索 — 交换律、结合律、一元一次方程与单位换算

一个交互式网页教学工具，帮助理解**交换律**、**结合律**、**一元一次方程求解**及**单位换算**（长度、面积、体积、容积、重量）。

## 快速开始

直接用浏览器打开 `index.html` 即可使用，无需任何依赖。

```
commutative-law-associative-law/
├── index.html    # 主页面
└── README.md     # 本文件
```

## 功能概览

页面包含四个 Tab 页签，可通过顶部按钮自由切换：

### 交换律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足交换律，减法/除法不满足 |
| 交互计算器 | 选择运算符（+ - x /），输入 a、b 两数，实时对比 `a op b` 与 `b op a` |
| 可视化柱状图 | 拖动滑块改变 a、b 的值，直观看到两边总高度始终一致 |
| 生活举例 | 数苹果和橙子，顺序不影响总数 |

### 结合律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足结合律，减法/除法不满足 |
| 交互计算器 | 输入 a、b、c 三数，对比 `(a op b) op c` 与 `a op (b op c)` |
| 分步计算 | 点击按钮逐步展开中间过程 |
| 可视化柱状图 | 三堆积木，两种分组方式，观察总数是否一致 |

### 一元一次方程

| 模块 | 说明 |
|------|------|
| 预设方程 | 5 个基础预设（含无解/无穷多解），一键加载 |
| 自定义方程 | 输入 `ax + b = cx + d` 系数，自由构造 |
| 逐步求解 | 分步展示（移项/合并/求解/检验），动画标注符号变化 |
| 天平可视化 | 4 阶段滑块，观察移项时天平如何保持平衡 |
| 去括号规则 | 三栏讲解 + 号、- 号、系数三种情况下的符号变化 |
| 去括号交互 | 自定义括号表达式，实时对比去括号前后，红色脉冲动画标注变号 |
| 含括号方程 | 4 个带括号预设，先展开再求解 |

### 单位换算

| 模块 | 说明 |
|------|------|
| 五种类型 | 长度、面积、体积、容积、重量，一键切换 |
| 双向换算 | 任意两个单位之间输入数值实时转换 |
| 思考过程 | 自动判断大→小（乘法）还是小→大（除法），展示完整推导思维链 |
| 进率链图 | 可视化展示跨级换算的每一步操作（逐级 × 或 ÷ 进率） |
| 进率表 | 当前类型所有相邻单位的进率一览表 |
| 规则详解 | 每类单位换算规则的文字讲解，包含进率由来 |
| 常见例题 | 预设例题一键加载，展示完整解答 |

#### 支持的单位

| 类型 | 单位 | 关键进率 |
|------|------|----------|
| 长度 | mm, cm, dm, m, km | 相邻 ×10（km 到 m 为 ×1000） |
| 面积 | mm², cm², dm², m², 公顷, km² | 相邻 ×100（长度进率 10 的平方） |
| 体积 | mm³, cm³, dm³, m³ | 相邻 ×1000（长度进率 10 的立方） |
| 容积 | mL, L | ×1000（1 L = 1000 mL = 1 dm³） |
| 重量 | g, kg, t | ×1000 |

## 交互说明

- **数值输入**：输入框中输入数字，结果实时更新
- **单位选择**：下拉框选择起始和目标单位，切换后自动重算
- **类型切换**：点击分类按钮切换单位类型，界面和例题同步更新
- **例题体验**：点击预设例题，自动填入数值并显示完整思考过程
- **结果反馈**：绿色 ✓ 表示成立/有解，红色 ✗ 表示不成立/无解
