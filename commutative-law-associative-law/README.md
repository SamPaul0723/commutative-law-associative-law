# 数学运算定律 — 交换律、结合律与一元一次方程

一个交互式网页教学工具，帮助理解**交换律**（Commutative Law）、**结合律**（Associative Law）以及**一元一次方程的求解步骤**（含去括号符号变化、移项变号）。

## 快速开始

直接用浏览器打开 `index.html` 即可使用，无需任何依赖。

```
commutative-law-associative-law/
├── index.html    # 主页面
└── README.md     # 本文件
```

## 功能概览

页面包含三个 Tab 页签，可通过顶部按钮自由切换：

### 交换律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足交换律，减法/除法不满足 |
| 交互计算器 | 选择运算符（+ - x /），输入 a、b 两数，实时对比 `a op b` 与 `b op a` 结果是否相等 |
| 可视化柱状图 | 拖动滑块改变 a、b 的值，直观看到两边总高度始终一致 |
| 生活举例 | 数苹果和橙子，顺序不影响总数 |

### 结合律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足结合律，减法/除法不满足 |
| 交互计算器 | 输入 a、b、c 三数，对比 `(a op b) op c` 与 `a op (b op c)` |
| 分步计算 | 点击「显示分步计算」按钮，逐步展开中间过程 |
| 可视化柱状图 | 三堆积木，两种分组方式，观察总数是否一致 |
| 生活举例 | 三堆苹果合并，先合哪两堆结果都一样 |

### 一元一次方程

| 模块 | 说明 |
|------|------|
| 概念讲解 | 一元一次方程的定义，核心思想——移项变号 |
| 预设方程 | 5 个基础预设（含无解/无穷多解情况），一键加载 |
| 自定义方程 | 输入 `ax + b = cx + d` 四个系数，自由构造方程 |
| 逐步求解 | 分步展示完整解题过程，每步有延迟动画和标签（移项/合并/求解/完成） |
| 一键展示 | 同时显示所有求解步骤 |
| 天平可视化 | 拖动滑块观察 4 个阶段（原始 → 移项变号 → 合并 → 求解），天平左右同步变化 |
| 去括号规则 | 三栏讲解：括号前是 + 号（不变号）、- 号（全变号）、系数（分配律展开） |
| 去括号交互 | 自定义括号表达式，实时对比去括号前后的符号变化，红色动画标注变号 |
| 含括号方程 | 4 个带括号的预设方程，先展开再求解 |

## 求解流程

```
去括号（留意 - 号全变） → 移项（过等号变号） → 合并同类项 → 系数化为 1 → 检验
```

## 交互说明

- **运算选择**：点击 + - x / 四个按钮切换运算符
- **数值输入**：直接在输入框中输入数字，结果实时更新
- **滑块调节**：拖动滑块改变可视化中的数值，柱状图同步变化
- **分步计算**：逐步展开解题中间过程，标注每一步的操作类型
- **去括号演示**：切换括号前符号，实时观察括号内各项符号是否翻转
- **天平可视化**：拖动步骤滑块，直观理解移项时天平两边如何保持平衡
- **结果反馈**：绿色 ✓ 表示定律成立 / 方程有解，红色 ✗ 表示不成立 / 无解
