## 功能概览

页面包含四个 Tab 页签，通过顶部按钮自由切换。

### 一、交换律

加法与乘法满足交换律（`a + b = b + a`），减法与除法不满足。

| 模块 | 说明 |
|------|------|
| 概念讲解 | 图示与文字说明，对比四种运算是否满足交换律 |
| 交互计算器 | 选择运算符（+ − × ÷），输入 a、b 两数，实时对比 `a op b` 与 `b op a` 的结果 |
| 可视化柱状图 | 拖动滑块改变 a、b 的值，直观看到两边总高度始终一致 |
| 生活举例 | 数苹果和橙子，顺序不影响总数 |

### 二、结合律

加法与乘法满足结合律（`(a + b) + c = a + (b + c)`），减法与除法不满足。

| 模块 | 说明 |
|------|------|
| 概念讲解 | 图示与文字说明，对比四种运算是否满足结合律 |
| 交互计算器 | 输入 a、b、c 三数，对比 `(a op b) op c` 与 `a op (b op c)` 的结果 |
| 分步计算 | 点击「显示分步计算」按钮，逐步展开中间过程 |
| 可视化柱状图 | 三堆积木，两种分组方式叠加，观察总数是否一致 |

### 三、一元一次方程

讲解标准形式 `ax + b = cx + d` 的求解步骤，重点突出**移项变号**和**去括号变号**两种符号变化规则。

#### 符号变化重点

| 场景 | 规则 | 动画效果 |
|------|------|----------|
| 移项变号 | 过等号时 + → −、− → + | 红色脉冲动画标注 |
| 去括号（− 号前） | 括号内各项全部变号 | 红色脉冲逐个标注 |
| 去括号（+ 号前） | 括号内各项符号不变 | 绿色提示 |

#### 模块详情

| 模块 | 说明 |
|------|------|
| 预设方程 | 5 个基础预设（含无解 / 无穷多解情况），一键加载 |
| 自定义方程 | 输入 `ax + b = cx + d` 四个系数，自由构造方程 |
| 逐步求解 | 动画分步展示：移项 → 合并同类项 → 系数化为 1 → 检验 |
| 一键展示 | 所有步骤同时展示，便于对比学习 |
| 天平可视化 | 4 阶段滑块（原始 → 移项变号 → 合并 → 求解），观察天平保持平衡 |
| 去括号规则卡 | 三栏列表讲解三种情况：括号前是 +、括号前是 −、括号前是系数 |
| 去括号交互 | 自定义括号表达式，实时对比去括号前后，标注每项符号变化 |
| 含括号方程 | 4 个带括号预设方程，自动先展开再去括号，再移项求解 |
| 口诀总结 | 步骤 0~4：去括号 → 移项 → 合并 → 求解 → 检验 |

### 四、单位换算

涵盖 5 类常用单位，支持双向换算，展示完整思考过程与进率链图。

#### 支持的 5 类单位

| 类型 | 包含单位 | 关键进率 |
|------|----------|----------|
| 长度 | mm, cm, dm, m, km | 相邻 ×10（km ↔ m 为 ×1000） |
| 面积 | mm², cm², dm², m², 公顷, km² | 相邻 ×100（长度进率 10 的平方，10²） |
| 体积 | mm³, cm³, dm³, m³ | 相邻 ×1000（长度进率 10 的立方，10³） |
| 容积 | mL, L | ×1000（1 L = 1000 mL = 1 dm³） |
| 重量 | g, kg, t | 相邻 ×1000 |

#### 模块详情

| 模块 | 说明 |
|------|------|
| 类型切换 | 顶部 5 个按钮一键切换单位类型，界面、进率表、例题同步更新 |
| 双向换算 | 选择起始/目标单位，输入数值，实时显示转换结果 |
| 思考过程 | 自动判断方向（大→小用乘法，小→大用除法），展示 4 步完整思维链 |
| 进率链图 | 可视化展示跨级换算的逐级操作路径，标注每一步的乘除运算 |
| 进率表 | 当前类型所有相邻单位的进率一览表 |
| 规则详解 | 每类单位换算规则的文字讲解，包含进率由来和与长度的关系 |
| 常见例题 | 每类 3~4 道预设例题，一键加载并显示完整解答 |

## 交互特性

- **实时响应**：输入数值后结果即时更新，无需点击提交按钮
- **动画标注**：符号变化触发脉冲动画（红色 = 正变负，绿色 = 负变正），直观醒目
- **双向选择**：下拉框自由选择起始和目标单位，切换后自动重算
- **分步展示**：求解步骤带时间延迟，逐步呈现，便于理解推理过程
- **结果反馈**：绿色 ✓ 表示成立 / 有解，红色 ✗ 表示不成立 / 无解
- **可视化图表**：柱状图（交换律/结合律）、天平（方程）、进率链（单位换算）
- **预设例题**：一键加载典型例子，降低上手门槛

## 求解流程

```
去括号（− 号前全部变号）
    ↓
移项变号（过等号 + ↔ −）
    ↓
合并同类项（左边合并 x，右边合并常数）
    ↓
系数化为 1（两边同除以 x 的系数）
    ↓
检验（代入原方程验证）
```
