# 四则运算定律 — 交换律与结合律

一个交互式网页教学工具，帮助理解四则运算中的**交换律**（Commutative Law）和**结合律**（Associative Law）。

## 快速开始

直接用浏览器打开 `index.html` 即可使用，无需任何依赖。

```
commutative-law-associative-law/
├── index.html    # 主页面
└── README.md     # 本文件
```

## 功能概览

页面包含两个 Tab 页签，可通过顶部按钮自由切换：

### 交换律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足交换律，减法/除法不满足 |
| 交互计算器 | 选择运算符（+ - x /），输入 a、b 两数，实时对比 `a op b` 与 `b op a` 结果是否相等 |
| 可视化柱状图 | 拖动滑块改变 a、b 的值，直观看到两边总高度始终一致 |
| 生活举例 | 数苹果和橙子，顺序不影响总数 |

### 结合律

| 模块 | 说明 |
|------|------|
| 概念讲解 | 加法/乘法满足结合律，减法/除法不满足 |
| 交互计算器 | 输入 a、b、c 三数，对比 `(a op b) op c` 与 `a op (b op c)` |
| 分步计算 | 点击「显示分步计算」按钮，逐步展开中间过程 |
| 可视化柱状图 | 三堆积木，两种分组方式，观察总数是否一致 |
| 生活举例 | 三堆苹果合并，先合哪两堆结果都一样 |

## 交互说明

- **运算选择**：点击 + - x / 四个按钮切换运算符
- **数值输入**：直接在输入框中输入数字，结果实时更新
- **滑块调节**：拖动滑块改变可视化中的数值，柱状图同步变化
- **分步计算**：结合律页面下的按钮，展示两种括号方式的中间步骤
- **结果反馈**：绿色勾表示定律成立，红色叉表示不成立
